# Plantilla procedimental: Resoluciones

Guía metodológica para revisar la trayectoria de expedientes que culminan en
una resolución administrativa. No es autoridad legal; los pasos obligatorios
deben verificarse con la norma vigente: `[VERIFICAR NORMA APLICABLE]`.

## Alcance

Aplicable a actos administrativos emitidos como resolución, con sus
antecedentes y trámite previo.

## Secuencia esperada (referencia)

```
INICIO → SOLICITUD / INICIO DE OFICIO → COMPETENCIA → ANTECEDENTES
→ INFORMES TÉCNICOS → INTERVENCIÓN JURÍDICA → INTERVENCIÓN CONTABLE
(cuando corresponda) → CONTRALOR → PROYECTO DE RESOLUCIÓN → APROBACIÓN
→ SUSCRIPCIÓN → NOTIFICACIÓN → PUBLICACIÓN (si corresponde) → EJECUCIÓN → ARCHIVO
```

## Etapas a evaluar

| Etapa | Qué verificar |
| --- | --- |
| Inicio | Solicitud o inicio de oficio |
| Competencia | Órgano con atribución |
| Antecedentes | Documentación previa |
| Informes | Sustento técnico |
| Intervención jurídica | Legalidad previa |
| Intervención contable | Impacto presupuestal |
| Contralor | Control interno/externo |
| Proyecto | Borrador del acto |
| Aprobación | Decisión válida |
| Suscripción | Firma del órgano competente |
| Notificación | Comunicación a interesados |
| Publicación | Requisito según la norma |
| Ejecución | Efectos del acto |

## Reglas

- No afirmar que un paso es obligatorio sin evidencia.
- La necesidad de informes, contralores y publicación depende de la norma
  vigente: `[VERIFICAR NORMA APLICABLE]`.
- No inventar plazos ni montos.
