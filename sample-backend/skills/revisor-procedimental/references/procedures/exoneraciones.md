# Plantilla procedimental: Exoneraciones

Guía metodológica para revisar la trayectoria de expedientes de exoneraciones
tributarias o de tasas (por ejemplo, exoneración de patente de rodados o de
otros tributos). No es autoridad legal; los requisitos y pasos obligatorios
deben verificarse con la norma vigente: `[VERIFICAR NORMA APLICABLE]`.

## Alcance

Aplicable a solicitudes de exención o reducción de tributos, tasas o patentes
del organismo.

## Secuencia esperada (referencia)

```
INICIO → SOLICITUD DEL INTERESADO → COMPETENCIA → ANTECEDENTES / LEGITIMACIÓN
→ VERIFICACIÓN DEL SUPUESTO DE EXONERACIÓN → INFORMES TÉCNICOS
→ INTERVENCIÓN JURÍDICA → INTERVENCIÓN CONTABLE/TRIBUTARIA → CONTRALOR
→ ACTO DE EXONERACIÓN → NOTIFICACIÓN → REGISTRO → ARCHIVO
```

## Etapas a evaluar

| Etapa | Qué verificar |
| --- | --- |
| Solicitud | Interesado y objeto |
| Legitimación | Titularidad del derecho invocado |
| Supuesto | Ajuste del caso al supuesto de exoneración |
| Informes | Verificación de condiciones |
| Intervención jurídica | Legalidad de la exención |
| Intervención contable | Impacto tributario |
| Contralor | Control interno/externo aplicable |
| Acto | Decisión fundada |
| Notificación | Comunicación al interesado |
| Registro | Asiento y efectos |
