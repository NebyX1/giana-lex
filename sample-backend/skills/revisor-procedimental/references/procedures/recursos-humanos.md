# Plantilla procedimental: Recursos Humanos

Guía metodológica para revisar la trayectoria de expedientes de personal
(designaciones, subrogaciones, licencias, compensaciones, sanciones y otras
actuaciones de RRHH). No es autoridad legal; los pasos obligatorios deben
verificarse con la norma vigente: `[VERIFICAR NORMA APLICABLE]`.

## Alcance

Aplicable a actuaciones que afectan la situación funcional del personal del
organismo.

## Secuencia esperada (referencia)

```
INICIO → SOLICITUD / INICIO DE OFICIO → COMPETENCIA → ANTECEDENTES
→ INFORMES TÉCNICOS (RRHH) → INTERVENCIÓN JURÍDICA → INTERVENCIÓN CONTABLE
(cuando afecta remuneraciones) → ACTO DE LA AUTORIDAD COMPETENTE
→ NOTIFICACIÓN AL INTERESADO → REGISTRO → EJECUCIÓN → ARCHIVO
```

## Etapas a evaluar

| Etapa | Qué verificar |
| --- | --- |
| Solicitud | Existencia y legitimación |
| Competencia | Órgano con atribución para el acto |
| Antecedentes | Legajo, cargos, antigüedad |
| Informes | Control técnico de RRHH |
| Intervención jurídica | Legalidad previa |
| Intervención contable | Impacto en remuneraciones |
| Acto | Decisión fundada |
| Notificación | Comunicación al interesado |
| Registro | Asiento en legajo |
| Ejecución | Efectos del acto |
