# Plantilla procedimental: Compras

Guía metodológica para revisar la trayectoria de expedientes de compras y
contrataciones. No es autoridad legal; los pasos obligatorios deben verificarse
con la norma vigente: `[VERIFICAR NORMA APLICABLE]`.

## Alcance

Aplicable a expedientes de adquisiciones, licitaciones, contrataciones directas
y demás modalidades de compra del organismo.

## Secuencia esperada (referencia)

```
INICIO → NECESIDAD / REQUERIMIENTO → PRESUPUESTO (disponibilidad)
→ ESTUDIOS / INFORMES TÉCNICOS → ELECCIÓN DE PROCEDIMIENTO DE CONTRATACIÓN
→ BASES / CONDICIONES → INTERVENCIÓN JURÍDICA → APROBACIÓN DEL PROCEDIMIENTO
→ PUBLICACIÓN / INVITACIÓN → RECEPCIÓN DE OFERTAS → EVALUACIÓN DE OFERTAS
→ ADJUDICACIÓN → CONTRATO → CONTRALOR → NOTIFICACIÓN → EJECUCIÓN → ARCHIVO
```

## Etapas a evaluar

| Etapa | Qué verificar |
| --- | --- |
| Requerimiento | Existencia de necesidad justificada |
| Presupuesto | Disponibilidad y afectación de crédito |
| Informes técnicos | Estudios previos requeridos |
| Bases | Condiciones definidas y aprobadas |
| Intervención jurídica | Control previo de legalidad |
| Publicación | Publicidad según el procedimiento |
| Evaluación | Criterios y actas de evaluación |
| Adjudicación | Acto, fundamento y competencia |
| Contrato | Firma, plazo y condiciones |
| Contralor | Control interno/externo aplicable |
| Notificación | Comunicación a interesados |

## Reglas

- No afirmar que un paso es obligatorio sin evidencia.
- El umbral y la modalidad dependen de la norma vigente: `[VERIFICAR NORMA APLICABLE]`.
- Las etapas de contralor y su obligatoriedad se verifican según el tipo de
  compra.
- No inventar plazos ni montos.
