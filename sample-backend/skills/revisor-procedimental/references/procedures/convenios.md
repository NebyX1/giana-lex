# Plantilla procedimental: Convenios

Guía metodológica para revisar la trayectoria de expedientes de aprobación de
convenios. No es autoridad legal; los pasos obligatorios deben verificarse con
la norma vigente: `[VERIFICAR NORMA APLICABLE]`.

## Alcance

Aplicable a convenios, acuerdos y protocolos suscritos por el organismo con
terceros (públicos o privados).

## Secuencia esperada (referencia)

```
INICIO → PROPUESTA / BORRADOR → COMPETENCIA → ANÁLISIS DE LA CONTRAPARTE
→ ANÁLISIS TÉCNICO DEL OBJETO → INTERVENCIÓN JURÍDICA (control de legalidad)
→ OBSERVACIONES / AJUSTES → APROBACIÓN DEL ÓRGANO COMPETENTE
→ FIRMA → REGISTRO / PUBLICACIÓN (si corresponde) → NOTIFICACIÓN
→ EJECUCIÓN → ARCHIVO
```

## Etapas a evaluar

| Etapa | Qué verificar |
| --- | --- |
| Propuesta | Existencia de borrador |
| Competencia | Órgano facultado para celebrar |
| Contraparte | Legitimación y capacidad |
| Objeto | Finalidad lícita y clara |
| Intervención jurídica | Legalidad previa del texto |
| Aprobación | Decisión del órgano competente |
| Firma | Suscripción válida |
| Registro | Asiento institucional |
| Publicación | Requisito según la norma |
| Ejecución | Cumplimiento del objeto |

## Reglas

- No afirmar que un paso es obligatorio sin evidencia.
- La necesidad de publicación, registro y contralor depende de la norma
  vigente: `[VERIFICAR NORMA APLICABLE]`.
- No inventar requisitos de forma ni montos.
