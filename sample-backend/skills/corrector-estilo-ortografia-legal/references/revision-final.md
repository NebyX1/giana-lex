# Revisión final

Lista de verificación para cerrar una corrección conservando el sentido jurídico.

## Comprobaciones

- [ ] No se alteró ninguna modalidad deóntica (`podrá`, `deberá`, etc.).
- [ ] No se modificó obligación, sujeto obligado, plazo, monto, competencia, excepción,
      prohibición, autorización, condición, alcance temporal ni referencia normativa.
- [ ] Ortografía, acentuación y puntuación corregidas sin cambiar el sentido.
- [ ] Terminología uniformada solo donde era evidente; denominaciones oficiales intactas.
- [ ] Inconsistencias (referencias, fechas, montos, numerales) marcadas, no resueltas
      arbitrariamente.
- [ ] No se "corrigieron" palabras jurídicas correctas ni nombres propios desconocidos.
- [ ] Fórmulas administrativas válidas conservadas.

## Salida

Cuando se pide "corrige este texto": devolver el texto corregido.

Si existen cambios potencialmente significativos, incluir:

```
TEXTO CORREGIDO

...

OBSERVACIONES JURÍDICO-LINGÜÍSTICAS
- ...
- ...
```

Si no hay observaciones relevantes, no añadir ruido.
