# Análisis de escenarios

Método para proyectar posibles desarrollos de una medida, distinguiendo claramente la
proyección de la certeza.

## Estructura estándar

- `ESCENARIO BASE`: el desarrollo más probable dado el estado actual.
- `ESCENARIO FAVORABLE`: desenlace positivo bajo condiciones propicias.
- `ESCENARIO ADVERSO`: desenlace negativo bajo condiciones desfavorables.
- **Factores de cambio**: condiciones que harían pasar de un escenario a otro.

## Criterios de construcción

1. **Supuestos explícitos**: declarar qué se asume para cada escenario.
2. **Coherencia**: cada escenario debe ser internamente consistente.
3. **Factores de sensibilidad**: identificar variables críticas (apoyo político, situación
   fiscal, reacción de actores, contexto externo).
4. **Probabilidad cualitativa**: asignar baja / media / alta solo cuando sea razonable.

## Reglas

- No presentar un escenario como predicción certera.
- No usar falsa precisión numérica salvo modelo real.
- Indicar qué datos verificarían o refutarían cada escenario.

## Salida sugerida

- Descripción de cada escenario.
- Factores que harían cambiar de escenario.
- Señales tempranas a monitorear.
