# Formato de informe jurídico

Guía metodológica para estructurar la salida del análisis. Plantilla de
contenido, no documento legal definitivo.

## Estructura interna

```
Conclusión
Fundamento
Normativa aplicable
Riesgos / incertidumbres
Datos pendientes
```

## Contenido por sección

### Conclusión
Respuesta directa a la cuestión planteada, en una o pocas frases. Solo afirmar
lo que el derecho verificado sustenta.

### Fundamento
Razonamiento que vincula regla y hecho. Separar claramente `HECHO` /
`AUTORIDAD` / `INFERENCIA`. Citar la fuente concreta de cada afirmación
normativa.

### Normativa aplicable
Lista de normas invocadas, con su estado de verificación y vigencia. Marcar las
no verificadas con `[VERIFICAR NORMA APLICABLE]`.

### Riesgos / incertidumbres
Puntos donde la conclusión es débil, existen contradicciones o faltan datos.
Calificar la confianza de cada afirmación.

### Datos pendientes
Información o normas que faltan para concluir con seguridad, con formato
`[DATO PENDIENTE: ...]`.

## Reglas

- No mezclar conveniencia política con validez jurídica.
- No concluir sobre puntos sin derecho suficientemente verificado.
- No inventar hechos ni normas para completar el informe.
- El informe es de análisis; si se requiere redactar un documento, se remite a
  la tarea de redacción.
