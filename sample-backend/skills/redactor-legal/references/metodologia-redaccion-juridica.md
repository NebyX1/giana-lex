# Metodología de redacción jurídica

Método original para crear documentos jurídicos y actos administrativos a partir de hechos,
derecho aplicable, tipo documental y objetivo.

## Principio

Se redacta sobre **hechos comprobados** y **derecho verificado**, nunca sobre suposiciones o
ejemplos usados como autoridad.

## Pasos de trabajo

1. **Identificar el tipo documental**: resolución, informe jurídico, nota administrativa, etc.
2. **Bloquear los hechos aportados**: solo usar hechos comprobados; no añadir otros.
3. **Identificar información indispensable**: qué falta para completar el acto.
4. **Recuperar patrón estilístico**: usar `ejemplos/` como patrón de **forma**, nunca como
   autoridad jurídica.
5. **Recuperar autoridad jurídica**: vía handoff a `investigador-normativo` o fuentes
   verificadas.
6. **Construir la estructura**: adecuada al tipo documental.
7. **Redactar**.
8. **Validar contenido**, citas, coherencia y pendientes.

## Estructura de una resolución

Aplicar `VISTO / RESULTANDO / CONSIDERANDO / ATENTO / RESUELVE` cuando corresponda.
**NO imponer** estas secciones a documentos que no las requieren (ej. informe jurídico).

## Reglas de evidencia

- Cada cita normativa debe provenir de fuente verificada.
- Nunca rellenar `[NORMA HABILITANTE]` basándose en el propio ejemplo.
- Usar placeholders del tipo `[DATO PENDIENTE: número de informe]`; nunca inventarlos.

## Salida

- Documento redactado (marcado como BORRADOR).
- Datos pendientes.
- Observaciones de consistencia.
