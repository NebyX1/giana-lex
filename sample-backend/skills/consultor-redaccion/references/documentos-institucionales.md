# Documentos institucionales

Guía para reconocer y estructurar los tipos de documento institucional que no son
necesariamente actos jurídicos formales.

## Tipos habituales

- **Informe**: documento que da cuenta de hechos o analiza un tema para una autoridad.
- **Memorando**: comunicación interna breve, orientada a una acción o decisión.
- **Nota**: comunicación formal breve entre órganos o personas.
- **Respuesta institucional**: contestación a una consulta o reclamo.
- **Exposición para la Junta**: presentación de un tema ante un cuerpo colegiado.
- **Comunicación interna**: aviso, convocatoria o información de circulación interna.

## Cómo estructurar según el tipo

- **Informe**: título, objeto, antecedentes, desarrollo, conclusiones y recomendaciones.
- **Memorando**: de / para / asunto, cuerpo, acción solicitada.
- **Nota**: destinatario, referencia, cuerpo, despedida y firma.
- **Exposición**: resumen ejecutivo, contexto, desarrollo, propuesta, fundamentación.

## Preguntas previas

- ¿Quién lee? ¿Qué debe decidir o comprender?
- ¿Qué formato espera la audiencia?
- ¿Qué información es imprescindible y cuál es secundaria?

## Reglas

- Adaptar el formato al tipo de documento; no imponer secciones que no correspondan.
- No convertir un documento de gestión en un acto administrativo formal (eso corresponde a
  `redactor-legal`).
- No inventar antecedentes ni cifras.
