# EJEMPLO — Designación para cometido específico

> **DOCUMENTO DE EJEMPLO. NO CONSTITUYE ACTO ADMINISTRATIVO NI FUENTE JURÍDICA.**

**Minas, [FECHA].**

**VISTO:** la necesidad de designar un/a funcionario/a responsable de [FUNCIÓN / ENLACE / COMETIDO].

**RESULTANDO:** que [NORMA / ORGANISMO / PROGRAMA] requiere la identificación de una persona responsable para [OBLIGACIONES].

**CONSIDERANDO:** que [FUNCIONARIO/A / CARGO] reúne las condiciones funcionales necesarias para asumir el cometido, sin perjuicio de las competencias de las demás dependencias.

**ATENTO:** a lo precedentemente expuesto, a [NORMA HABILITANTE] y a sus facultades legales.

El Intendente Departamental de Lavalleja,

**RESUELVE:**

**1°.-** Desígnase a [NOMBRE / CARGO], a partir de [FECHA], para actuar como [FUNCIÓN / ENLACE / REFERENTE] de la Intendencia Departamental de Lavalleja ante [ORGANISMO / ÁREA].

**2°.-** Notifíquese personalmente a la persona designada.

**3°.-** Comuníquese a [ORGANISMO EXTERNO] y a [DEPENDENCIAS INTERNAS] a sus efectos.

**4°.-** Cumplido, archívese.

[FIRMAS]

## Datos que el agente debe exigir

- Cometido concreto.
- Norma o acto que exige la designación.
- Persona y cargo.
- Vigencia.
- Organismos que deben ser notificados.
