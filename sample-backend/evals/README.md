# Evaluaciones juridicas

Esta carpeta contiene casos validados, separados de los tests tecnicos. No se incorporan respuestas juridicas inventadas.

- `retrieval/`: calidad de recuperacion y fuentes.
- `resolutions/`: estructura y hallazgos de resoluciones.
- `citations/`: extraccion y verificacion de referencias.
- `procedures/`: secuencias administrativas validadas.
